# IBC Egress Requirements — Reference

Source: International Building Code (IBC), Chapter 10 — Means of Egress
Key tables: 1004.5 (occupant load factors), 1006.2.1 (common path), 1006.3.1 (exits),
1017.2 (travel distance), 1020.2 (corridor width)

---

## Overview

Means of egress = the continuous path of travel from any occupied point in a building
to the public way. Three components:
1. **Exit access** — the path from an occupied space TO an exit (corridors, aisles, rooms)
2. **Exit** — the protected portion (exit stairway, exit passageway, exterior exit door)
3. **Exit discharge** — the path FROM the exit to the public way

## Number of Exits Required (IBC 1006.3.1)

| Occupant Load per Story | Min Exits Required |
|---|---|
| 1–500 | 2 |
| 501–1,000 | 3 |
| >1,000 | 4 |

### Exceptions — Single Exit Allowed
A **single exit** is permitted under specific conditions (IBC Table 1006.3.4):

| Occupancy | Max Stories | Max Occupants/Floor | Max Travel Distance |
|---|---|---|---|
| A, B, E, F, M, U | 1 story | 49 | 75 ft (S) / 100 ft (NS) |
| R-2 (apartments) | 1 story above grade | 4 dwelling units / floor | 125 ft (S) |
| R-3 | 3 stories | — | — |
| S-2 (parking) | 1 story | 29 | 100 ft (S) |

**(S) = Sprinklered, (NS) = Non-sprinklered**

## Corridor Requirements (IBC 1020)

### Minimum Corridor Width (IBC 1020.2)

| Occupancy/Condition | Min Width |
|---|---|
| Group E (educational) with occupant load >100 | 72 in (6 ft) |
| Group I-2 (hospital) — required for bed movement | 96 in (8 ft) |
| All other corridors with occupant load >50 | 44 in |
| All other corridors with occupant load ≤50 | 36 in |
| Access to residential dwelling units (R-2) | 36 in |

### Corridor Fire-Resistance Rating (IBC Table 1020.1)

| Occupancy | Required Corridor Rating |
|---|---|
| H-1, H-2, H-3 | 1 hr (regardless of sprinklers) |
| H-4, H-5 | 1 hr (NS) / 0 hr (S) |
| A, B, E, F, M, S, U (occupant load >30) | 1 hr (NS) / 0 hr (S) |
| R (occupant load >10) | 1 hr (NS) / 0.5 hr (S) — but R-2 corridors serving >10 still need 0.5 hr even with sprinklers |
| I-2 | 0 hr if smoke compartments per 407.4 |
| I-1, I-3 | 1 hr (NS) / 0 hr (S) |

## Exit Width Calculations (IBC 1005.1)

Minimum width of exits is calculated based on occupant load:

| Component | Width Factor |
|---|---|
| **Stairways** | 0.3 inches per occupant |
| **Other egress components** (doors, corridors, ramps) | 0.2 inches per occupant |

**Sprinklered buildings**: May use 0.2 in/occupant for stairs and 0.15 in/occupant for
other components (IBC 1005.1, Exception).

### Minimum Component Widths (regardless of calculation)
- Exit door: 32 in clear width (IBC 1010.1.1)
- Stairway: 44 in (occupant load >50) or 36 in (occupant load ≤50)
- Corridor: See corridor table above

## Stairway Requirements (IBC 1011)

| Parameter | Requirement |
|---|---|
| Min width | 44 in (>50 occupants) / 36 in (≤50 occupants) |
| Min headroom | 6 ft 8 in |
| Max riser height | 7 in (IBC) / 7.75 in (IRC residential) |
| Min riser height | 4 in |
| Min tread depth | 11 in |
| Max variation between risers | 3/8 in |
| Handrail height | 34–38 in |
| Handrail required | Both sides for stairs >44 in wide |
| Intermediate handrail | Required when stair >60 in wide |
| Landing depth | Min equal to stair width (max 48 in required) |

## Exit Signs and Emergency Lighting (IBC 1013, 1008)

- Exit signs required at all exits and exit access doors
- Emergency lighting required in all exit access corridors, exit stairways, and exit discharge paths
- Emergency lighting must provide 90 minutes of illumination upon power failure
- Min illumination: 1 foot-candle average, 0.1 foot-candle minimum at floor level
