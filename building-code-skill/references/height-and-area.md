# IBC Allowable Height and Area — Reference

Source: International Building Code (IBC), Chapter 5 — General Building Heights and Areas
Key tables: 504.3 (stories), 504.4 (height in feet), 506.2 (area per floor)

---

## Overview

IBC Chapter 5 determines the maximum number of stories, building height (in feet),
and floor area allowed based on:
1. **Occupancy group** (what the building is used for)
2. **Construction type** (how it's built — Type I-A through V-B)
3. **Sprinkler status** (sprinklered buildings get bonuses)
4. **Frontage** (open perimeter can increase allowable area)

## Sprinkler Increases (IBC 504.2 and 506.3)

### Height and Story Increases (Section 504.2)
Buildings with an NFPA 13 sprinkler system receive:
- **+1 story** above the tabular value in Table 504.3
- **+20 feet** above the tabular value in Table 504.4
- Does NOT apply to Type I-A (already unlimited) or certain H/I occupancies

### Area Increase for Sprinklers (Section 506.3)
Buildings with an NFPA 13 sprinkler system:
- **Multi-story**: Area per floor multiplied by **3** (200% increase)
- **Single-story**: Area per floor multiplied by **4** (300% increase)
- Does NOT apply to Type I-A or I-B (already unlimited) or Group H

### Frontage Increase (Section 506.2)
If the building has open space (public way, yard, open space) on its perimeter:
- Additional area increase based on percentage of perimeter with frontage
- Formula: If = [F/P - 0.25] × W/30
- Where F = frontage length, P = perimeter, W = width of open space
- Max increase: 75%

### Combined Increases
Sprinkler and frontage increases are **multiplicative**, not additive:
- Allowable area = Tabular area × (1 + If) × sprinkler multiplier
- This can significantly increase the allowable area

## Common Scenarios

### 5-Over-1 (Podium Building)
- Ground floor: Type I-A concrete podium (S-2 parking or M/B commercial)
- Upper floors: Type III-A or V-A wood frame (R-2 apartments)
- IBC 510.2 allows this configuration — the podium is a separate building
  for height/area purposes
- Very common for urban mixed-use apartment buildings

### Type V-A Apartment Building (R-2)
- Base: 3 stories, 70 ft, 12,000 sqft/floor
- With NFPA 13R sprinklers: 4 stories, 70 ft (NFPA 13R does NOT get +20 ft height)
- With NFPA 13 sprinklers: 4 stories, 90 ft, 36,000 sqft/floor
- Note: R-2 buildings 4 stories or less can use NFPA 13R instead of full NFPA 13

### Type V-B Single Family (R-3)
- Stories, height, and area are all **unlimited** for R-3
- But practical limits come from the IRC (International Residential Code) which
  governs 1-2 family dwellings up to 3 stories
