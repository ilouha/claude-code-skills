# IBC Construction Types — Reference

Source: International Building Code (IBC), Chapter 6 — Types of Construction
IBC Table 601: Fire-Resistance Rating Requirements for Building Elements

---

## Overview

The IBC defines **5 construction types**, each with an **A and B subtype** (10 total).
The type determines the fire-resistance ratings required for structural elements.
Higher numbers = less fire resistance. A subtypes > B subtypes within each number.

**Type I** = Most fire-resistant (noncombustible, high ratings)
**Type V** = Least fire-resistant (combustible, low or no ratings)

---

## Type I — Noncombustible, Fire-Resistive

### Type I-A (Highest fire resistance)
- **Structural frame**: 3 hr
- **Bearing walls (exterior)**: 3 hr
- **Bearing walls (interior)**: 3 hr
- **Non-bearing walls (interior)**: 0 hr
- **Floor construction**: 2 hr
- **Roof construction**: 1.5 hr
- **Materials**: Noncombustible (steel, concrete, masonry)
- **Typical uses**: High-rises, hospitals, large assembly buildings
- **Notes**: No height limit in IBC. Most protective construction type.

### Type I-B
- **Structural frame**: 2 hr
- **Bearing walls (exterior)**: 2 hr
- **Bearing walls (interior)**: 2 hr
- **Non-bearing walls (interior)**: 0 hr
- **Floor construction**: 2 hr
- **Roof construction**: 1 hr
- **Materials**: Noncombustible
- **Typical uses**: Mid-rise to high-rise office, residential, institutional

---

## Type II — Noncombustible, Non-Fire-Resistive

### Type II-A
- **Structural frame**: 1 hr
- **Bearing walls (exterior)**: 1 hr
- **Bearing walls (interior)**: 1 hr
- **Non-bearing walls (interior)**: 0 hr
- **Floor construction**: 1 hr
- **Roof construction**: 1 hr
- **Materials**: Noncombustible (typically steel frame)
- **Typical uses**: Mid-rise offices, retail, hotels, apartments (4-5 stories)

### Type II-B (Unprotected noncombustible)
- **Structural frame**: 0 hr
- **Bearing walls (exterior)**: 0 hr
- **Bearing walls (interior)**: 0 hr
- **Non-bearing walls (interior)**: 0 hr
- **Floor construction**: 0 hr
- **Roof construction**: 0 hr
- **Materials**: Noncombustible but no fire-resistance required
- **Typical uses**: Warehouses, low-rise retail, metal buildings, strip malls
- **Notes**: The most common type for single-story commercial/industrial buildings

---

## Type III — Exterior Noncombustible, Interior Combustible

### Type III-A
- **Structural frame**: 1 hr
- **Bearing walls (exterior)**: 2 hr (noncombustible required)
- **Bearing walls (interior)**: 1 hr
- **Non-bearing walls (interior)**: 0 hr
- **Floor construction**: 1 hr
- **Roof construction**: 1 hr
- **Materials**: Exterior walls must be noncombustible; interior structure may be combustible (wood)
- **Typical uses**: 3-4 story mixed-use, apartments over retail (the classic "5-over-1" podium uses this for the wood portion above a Type I-A podium)

### Type III-B
- **Structural frame**: 0 hr
- **Bearing walls (exterior)**: 2 hr (noncombustible required)
- **Bearing walls (interior)**: 0 hr
- **Non-bearing walls (interior)**: 0 hr
- **Floor construction**: 0 hr
- **Roof construction**: 0 hr
- **Materials**: Exterior walls noncombustible; interior may be unprotected combustible
- **Typical uses**: Small commercial with masonry/concrete exterior walls

---

## Type IV — Heavy Timber (Mass Timber)

### Type IV-A (2021 IBC — Tall Mass Timber)
- **Structural frame**: 3 hr
- **Bearing walls (exterior)**: 3 hr
- **Bearing walls (interior)**: 3 hr
- **Floor construction**: 2 hr
- **Roof construction**: 1.5 hr
- **Materials**: Mass timber (CLT, glulam, NLT) with noncombustible protection
- **Notes**: Added in 2021 IBC. Allows up to 18 stories. All mass timber must be fully encapsulated in noncombustible material.

### Type IV-B (2021 IBC)
- **Structural frame**: 2 hr
- **Bearing walls (exterior)**: 2 hr
- **Bearing walls (interior)**: 2 hr
- **Floor construction**: 2 hr
- **Roof construction**: 1 hr
- **Materials**: Mass timber with noncombustible protection (some exposed timber allowed)
- **Notes**: Up to 12 stories per 2021 IBC

### Type IV-C (2021 IBC)
- **Structural frame**: 2 hr
- **Bearing walls (exterior)**: 2 hr
- **Bearing walls (interior)**: 2 hr
- **Floor construction**: 2 hr
- **Roof construction**: 1 hr
- **Materials**: Mass timber — exposed timber surfaces permitted
- **Notes**: Up to 9 stories per 2021 IBC. Most common mass timber type.

### Type IV-HT (Heavy Timber — Traditional)
- **Structural frame**: HT (prescriptive heavy timber dimensions)
- **Bearing walls (exterior)**: 2 hr
- **Bearing walls (interior)**: 1 hr / HT
- **Floor construction**: HT
- **Roof construction**: HT
- **Materials**: Traditional heavy timber (min 6×8 columns, 6×10 beams, 3-in decking)
- **Typical uses**: Renovated mill buildings, restaurants, breweries
- **Notes**: HT = prescriptive heavy timber dimensions per IBC 2304.11, not a rated assembly

---

## Type V — Combustible (Wood Frame)

### Type V-A (Protected wood frame)
- **Structural frame**: 1 hr
- **Bearing walls (exterior)**: 1 hr
- **Bearing walls (interior)**: 1 hr
- **Non-bearing walls (interior)**: 0 hr
- **Floor construction**: 1 hr
- **Roof construction**: 1 hr
- **Materials**: Combustible (wood frame) with 1-hr fire-resistance protection
- **Typical uses**: 2-3 story apartments, townhouses, small mixed-use
- **Notes**: Very common for multi-family residential. Wood frame with gypsum board protection.

### Type V-B (Unprotected wood frame)
- **Structural frame**: 0 hr
- **Bearing walls (exterior)**: 0 hr
- **Bearing walls (interior)**: 0 hr
- **Non-bearing walls (interior)**: 0 hr
- **Floor construction**: 0 hr
- **Roof construction**: 0 hr
- **Materials**: Combustible — no fire-resistance protection required
- **Typical uses**: Single-family homes, small commercial, garages
- **Notes**: Most residential single-family homes are Type V-B. Simplest and cheapest to build.
