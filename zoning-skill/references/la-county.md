## Accessory Dwelling Units (ADUs) & Junior ADUs (JADUs)

### JADU (Junior Accessory Dwelling Unit)

A JADU is a small residential unit contained entirely within an existing single-family dwelling or attached garage.

#### JADU Development Standards

| Standard | Requirement |
|---|---|
| **Max Size** | 500 SF |
| **Location** | Must be entirely within an existing single-family residence or attached garage |
| **Separate Entrance** | Required — must have an exterior door leading outside |
| **Kitchen** | Kitchenette with cooking facilities required |
| **Bathroom** | Not required — may share sanitation facilities with primary dwelling |
| **Fire-Rated Separation** | Not required — JADU is considered part of the main structure |
| **Owner Occupancy** | Yes — owner must occupy either the primary dwelling or the JADU |
| **Parking** | None required |
| **Separate Sale** | Not permitted — cannot be sold independently from the primary dwelling |
| **Setbacks** | N/A — JADU is contained within the existing structure, so no independent setback requirements apply. The primary dwelling's existing setbacks govern. |

#### Key JADU Notes
- A JADU does not create new building footprint — it converts existing space
- One JADU is allowed per single-family lot
- A JADU + one ADU can coexist on the same single-family lot (per California state law)
- JADU is not considered a separate unit for fire/life safety purposes
- Building permits are still required for the conversion

### ADU (Accessory Dwelling Unit) — Detached

#### Detached ADU Development Standards (Single-Family Lot)

| Standard | Requirement |
|---|---|
| **Max Size** | 800 SF (one bedroom) or 1,000 SF (two+ bedrooms) |
| **Max Height** | 16 ft |
| **Side Setback** | 4 ft |
| **Rear Setback** | 4 ft |
| **Front Setback** | Per underlying zone |
| **Parking** | None required (per California state law) |
| **Separate Sale** | Not permitted (unless AB 1033 local opt-in applies) |

#### Attached ADU Development Standards

| Standard | Requirement |
|---|---|
| **Max Size** | 1,200 SF (per LA County; state law floor is 800 SF) |
| **Max Height** | Must not exceed primary dwelling height |
| **Side Setback** | 4 ft (for any new construction/addition beyond existing walls) |
| **Rear Setback** | 4 ft (for any new construction/addition beyond existing walls) |
| **Front Setback** | Per underlying zone (typically 20-25 ft) |
| **Fire-Rated Separation** | Required — 1-hour fire-rated wall between ADU and primary dwelling |
| **Kitchen** | Full kitchen required |
| **Bathroom** | Full bathroom required |
| **Separate Entrance** | Required |
| **Parking** | None required (per California state law) |
| **Owner Occupancy** | Not required (per California state law) |
| **Separate Sale** | Not permitted (unless AB 1033 local opt-in applies) |
| **Impact Fees** | Exempt if under 750 SF; proportional if 750-1,200 SF |

#### Key Attached ADU Notes
- Can expand beyond existing building footprint (unlike JADU)
- New exterior walls must meet 4 ft side/rear setbacks
- If addition stays within existing building envelope, existing setbacks are grandfathered
- Fire-rated separation adds cost vs. JADU (which does not require it)
- No owner occupancy requirement — can rent both primary dwelling and ADU

#### ADU — Garage Conversion

| Standard | Requirement |
|---|---|
| **Setbacks** | Existing garage setbacks are grandfathered — no new setback compliance needed |
| **Replacement Parking** | Not required |
| **Size** | Limited to existing garage footprint |

---

### ADU + JADU Combinations

California state law allows the following on a single-family lot:
- **1 detached ADU + 1 JADU** (maximum)
- The ADU and JADU are separate units with separate rules
- Owner occupancy required for JADU only (not for ADU, per state law)

## Key California State Law Overrides (Apply to All LA County)

### ADU Laws (AB 68, SB 13, AB 881, AB 587, AB 1033)
- ADUs and JADUs allowed by right in all residential zones
- Counties/cities cannot impose min lot sizes for ADUs
- Owner occupancy cannot be required for ADUs (only JADUs)
- Parking cannot be required for ADUs
- Impact fees cannot be charged for ADUs under 750 SF

### SB 9 (Housing Opportunity and More Efficiency Act)
- Allows lot splits and duplexes on single-family zoned lots
- Applies in unincorporated urban areas
- Requirements: Not historic district, not VHFHSZ, owner-occupied (for lot split)

## Caveats
- Always verify parcel-specific zoning with [LA County Planning](https://planning.lacounty.gov)
- Some unincorporated areas have specific plans or overlay zones that modify base rules
- Hillside and fire hazard areas have additional restrictions
- ADU/JADU regulations are subject to frequent state law updates — verify current rules
- This is general guidance — consult LA County Building & Safety or a licensed architect before construction
